# 💱 Currency Converter

A responsive currency converter web application built using HTML, CSS, and JavaScript. The application uses a currency exchange-rate API to provide up-to-date conversion rates between different currencies.

## 🚀 Live Demo

Coming soon...

## 📌 Features

- 🌍 Supports multiple currencies
- 💱 Real-time exchange-rate conversion
- 🔄 Swap From/To currencies
- 🚩 Dynamic country flags
- 🌙 Dark Mode / Light Mode
- 💾 Conversion history using Local Storage
- 🕒 Date and time for conversion history
- 🗑️ Clear conversion history
- 🔢 Amount validation
- ⏳ Loading indicator while fetching rates
- ⚠️ API error handling
- 📱 Responsive design for desktop and mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Local Storage
- Font Awesome

## 🔌 API

This project uses the Fawaz Ahmed currency API to retrieve exchange-rate data.

API:

https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@latest/v1/currencies
